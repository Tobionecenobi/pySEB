# Mathematica derivations

The `.nb` notebooks and corresponding `.pdf` exports derive the original SEB
scattering expressions. See [the download index](index.qmd) for the subunits.
Their scientific contents and historical filenames are unchanged.

The SymPy spheroid derivation is in [../spheroid/spheroid.qmd](../spheroid/spheroid.qmd).
Numerical sampling programs moved to `Tests/sampling/`, and existing sampled
reference curves moved to `Tests/data/sampling/` at the repository root.
