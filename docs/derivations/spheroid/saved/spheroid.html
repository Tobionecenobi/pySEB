Tutorial: deriving a spheroid SEB subunit with SymPy

This notebook is a second worked example for deriving a SEB subunit. The shape is a homogeneous spheroid: an axisymmetric ellipsoid with equatorial semi-axis a and polar semi-axis c.

The spheroid is the special case a = b of the triaxial ellipsoid:

\[\frac{x^2+y^2}{a^2}+\frac{z^2}{c^2}\le 1.\]

The picture below uses the same convention throughout the derivation: a is an equatorial semi-axis and c is the polar semi-axis.

We will derive the formulas in the same order a subunit implementation usually needs them. First we describe the geometry. Then we write the centered scattering amplitude. After that we move the reference point away from the center, first to named axis tips and then to a distributed point on the surface. Finally we expand everything near q = 0 and use small numerical functions to check that the expressions behave as expected.

The main simplification is symmetry. A triaxial ellipsoid needs two orientation variables because all three axes are different. A spheroid can spin freely around its polar axis without changing its shape, so one orientation variable is enough. Most of this notebook is about using that symmetry carefully without losing the reference-point names SEB expects.

We use the same reference-point style as in the triaxial tutorial:

  • center
  • the four equatorial axis-tip points pole_a_plus, pole_a_minus, pole_b_plus, pole_b_minus
  • the two polar axis-tip points pole_c_plus, pole_c_minus
  • the distributed reference point equator, chosen uniformly around the equatorial ring
  • the distributed reference point surface, chosen uniformly over the spheroid surface area

The two equatorial axes are symmetry-equivalent. We still keep both pole_a_* and pole_b_* as names because a SEB subunit often needs stable, explicit reference-point names.

0. Shared scattering idea

Before touching the spheroid, we start with the one idea that all the later expressions reuse: scattering is phase bookkeeping. Each point in the object emits a wave contribution, and the detector sees the result of adding those contributions.

For a scatterer at position r, the phase for a detector pixel selected by scattering vector q is

\[e^{i\mathbf q\cdot\mathbf r}.\]

For a randomly oriented object, pair phases average to the Debye factor

\[\left\langle e^{i\mathbf q\cdot\mathbf r}\right\rangle =\frac{\sin(qr)}{qr}.\]

SEB subunits need three related quantities:

  • the form factor F(q), comparing all pairs of scatterers inside the body
  • form factor amplitudes A_ref(q), comparing the body to one reference point
  • phase factors Psi_ref1_ref2(q), comparing two reference points

The normalized amplitude of a homogeneous sphere is the kernel

\[K(z)=3\frac{\sin z-z\cos z}{z^3}.\]

NoteDerivation of the spherical kernel

Start with a homogeneous sphere of radius R. Its normalized amplitude is the volume average of the phase factor:

\[K(qR)=\frac{1}{V}\int_{|\mathbf r|\le R} e^{i\mathbf q\cdot\mathbf r}\,d^3r,\]

where

\[V=\frac{4\pi R^3}{3}.\]

Because the sphere is rotationally symmetric, choose the polar axis along q. Then

\[\mathbf q\cdot\mathbf r = qr\cos\theta,\]

and the angular average at fixed r is the Debye factor:

\[\frac{1}{4\pi}\int e^{iqr\cos\theta}\,d\Omega =\frac{\sin(qr)}{qr}.\]

So the normalized amplitude becomes

\[K(qR) =\frac{4\pi}{V}\int_0^R r^2\frac{\sin(qr)}{qr}\,dr.\]

Substitute the sphere volume:

\[K(qR) =\frac{3}{R^3}\int_0^R r^2\frac{\sin(qr)}{qr}\,dr =\frac{3}{qR^3}\int_0^R r\sin(qr)\,dr.\]

The remaining integral is

\[\int r\sin(qr)\,dr =-\frac{r\cos(qr)}{q}+\frac{\sin(qr)}{q^2}.\]

Evaluating from 0 to R gives

\[K(qR) =\frac{3}{qR^3} \left( -\frac{R\cos(qR)}{q} +\frac{\sin(qR)}{q^2} \right).\]

Collecting powers of qR,

\[K(qR) =3\frac{\sin(qR)-qR\cos(qR)}{(qR)^3}.\]

Finally define

\[z=qR.\]

Then

\[K(z)=3\frac{\sin z-z\cos z}{z^3}.\]

1. Geometry

Now we turn the physical picture into a formula. The trick is to avoid integrating directly over a spheroid. Instead, we start with a sphere, where the answer is already known, and stretch the coordinates. The price of that stretch is that the sphere radius inside K(qR) becomes an orientation-dependent effective radius.

Start from a unit sphere with coordinates (X,Y,Z) and stretch it into a spheroid:

\[x=aX,\qquad y=aY,\qquad z=cZ.\]

For a fixed orientation,

\[\mathbf q\cdot\mathbf r=(aq_x)X+(aq_y)Y+(cq_z)Z.\]

So the sphere kernel is evaluated at an effective length

\[R_{\mathrm{eff}}=\sqrt{a^2(e^2+f^2)+c^2g^2},\]

where (e,f,g) are direction cosines of the scattering direction relative to the spheroid axes. By axial symmetry, only the magnitude of the polar direction cosine matters. We fold the full range -1 <= g <= 1 onto

\[u=|g|,\qquad 0\le u\le 1.\]

The two transverse direction cosines satisfy e^2 + f^2 = 1 - u^2, so the two equatorial terms combine. This is the exact step where the spheroid becomes simpler than the general ellipsoid:

Then

\[R_{\mathrm{eff}}(u)=\sqrt{a^2(1-u^2)+c^2u^2}.\]

The orientation average over the full sphere reduces to

\[\langle h\rangle=\int_0^1 h(u)\,du.\]

In the code cell below, we encode just those pieces: the symbols, the effective radius, and the sphere kernel evaluated at q R_eff(u). We keep the expressions symbolic because the notebook is meant to document the formulas, not just produce numbers.

import sympy as sp
from IPython.display import Math, display

q, a, c = sp.symbols("q a c", positive=True, real=True)
u = sp.Symbol("u", real=True)

Reff2 = a**2 * (1 - u**2) + c**2 * u**2
Reff = sp.sqrt(Reff2)

def sphere_kernel(z):
    return 3 * (sp.sin(z) - z * sp.cos(z)) / z**3

def sinc(z):
    return sp.sin(z) / z

K = sphere_kernel(q * Reff)

display(Math(r"R_{\mathrm{eff}}(u) = " + sp.latex(Reff)))
display(Math(r"K(qR_{\mathrm{eff}}(u)) = " + sp.latex(K)))

\(\displaystyle R_{\mathrm{eff}}(u) = \sqrt{a^{2} \left(1 - u^{2}\right) + c^{2} u^{2}}\)

\(\displaystyle K(qR_{\mathrm{eff}}(u)) = \frac{- 3 q \sqrt{a^{2} \left(1 - u^{2}\right) + c^{2} u^{2}} \cos{\left(q \sqrt{a^{2} \left(1 - u^{2}\right) + c^{2} u^{2}} \right)} + 3 \sin{\left(q \sqrt{a^{2} \left(1 - u^{2}\right) + c^{2} u^{2}} \right)}}{q^{3} \left(a^{2} \left(1 - u^{2}\right) + c^{2} u^{2}\right)^{\frac{3}{2}}}\)

2. Form factor and center amplitude

For one fixed spheroid orientation, the normalized amplitude relative to the center is K(q R_eff(u)).

There are two closely related quantities here, and it is easy to mix them up:

  • A_center(q) is an amplitude. We average K itself.
  • F(q) is an intensity. We average K^2.

That difference is why the two formulas below look almost identical but have different powers of K.

The form factor is the orientation average of the squared amplitude:

\[F(q)=\int_0^1 K(qR_{\mathrm{eff}}(u))^2\,du.\]

The center amplitude is

\[A_{\mathrm{center}}(q)=\int_0^1 K(qR_{\mathrm{eff}}(u))\,du.\]

For a general spheroid, these are well-behaved one-dimensional quadratures.

The next cell does not ask SymPy to evaluate the integrals. It writes the integrals explicitly, which is the form we would normally translate into a SEB expression or a numerical quadrature.

F = sp.Integral(K**2, (u, 0, 1))
A_center = sp.Integral(K, (u, 0, 1))

display(Math(r"F(q) = " + sp.latex(F)))
display(Math(r"A_{\mathrm{center}}(q) = " + sp.latex(A_center)))

\(\displaystyle F(q) = \int\limits_{0}^{1} \frac{\left(- 3 q \sqrt{a^{2} \left(1 - u^{2}\right) + c^{2} u^{2}} \cos{\left(q \sqrt{a^{2} \left(1 - u^{2}\right) + c^{2} u^{2}} \right)} + 3 \sin{\left(q \sqrt{a^{2} \left(1 - u^{2}\right) + c^{2} u^{2}} \right)}\right)^{2}}{q^{6} \left(a^{2} \left(1 - u^{2}\right) + c^{2} u^{2}\right)^{3}}\, du\)

\(\displaystyle A_{\mathrm{center}}(q) = \int\limits_{0}^{1} \frac{- 3 q \sqrt{a^{2} \left(1 - u^{2}\right) + c^{2} u^{2}} \cos{\left(q \sqrt{a^{2} \left(1 - u^{2}\right) + c^{2} u^{2}} \right)} + 3 \sin{\left(q \sqrt{a^{2} \left(1 - u^{2}\right) + c^{2} u^{2}} \right)}}{q^{3} \left(a^{2} \left(1 - u^{2}\right) + c^{2} u^{2}\right)^{\frac{3}{2}}}\, du\)

In the sphere limit a = c = R, the effective radius is constant and the usual sphere expressions are recovered.

This is our first sanity check. If the spheroid derivation cannot turn back into the sphere when a and c are equal, then something has gone wrong before we even reach reference points.

R = sp.symbols("R", positive=True, real=True)
K_sphere = sp.simplify(sphere_kernel(q * R))

display(Math(r"F_{\mathrm{sphere}}(q) = " + sp.latex(sp.simplify(K_sphere**2))))
display(Math(r"A_{\mathrm{center,sphere}}(q) = " + sp.latex(K_sphere)))

\(\displaystyle F_{\mathrm{sphere}}(q) = \frac{9 \left(R q \cos{\left(R q \right)} - \sin{\left(R q \right)}\right)^{2}}{R^{6} q^{6}}\)

\(\displaystyle A_{\mathrm{center,sphere}}(q) = \frac{3 \left(- R q \cos{\left(R q \right)} + \sin{\left(R q \right)}\right)}{R^{3} q^{3}}\)

At q = 0, direct substitution into the raw kernel gives a removable singularity. Use the kernel limit:

This is a common pattern in scattering code. The formula has z^3 in the denominator, but the limit is perfectly finite because the numerator vanishes to the same order. In production code, the kernel should be evaluated by a stable helper or by an explicit small-z series.

display(Math(r"F(0) = " + sp.latex(F_q0)))

3. Specific surface reference points

The centered amplitude measured phases relative to the origin. A named reference point changes the phase origin. This is the step where the vector r - R_ref appears, so let us spell it out.

For one fixed orientation, the normalized amplitude relative to the center is the volume average

\[ A_{\mathrm{center}}(\mathbf q) =\frac{1}{V}\int_{\mathrm{body}} e^{i\mathbf q\cdot\mathbf r}\,dV. \]

Here r is the position of a scattering volume element measured from the center of the spheroid. If SEB asks for the amplitude relative to a different reference point, we measure the same scatterer from that reference point instead. The relative vector from the reference point to the scatterer is

\[ \mathbf r_{\mathrm{from\ ref}} =\mathbf r-\mathbf R_{\mathrm{ref}}. \]

That subtraction is just ordinary coordinate bookkeeping. If the reference point is at R_ref and the scatterer is at r, then “scatterer relative to reference” means destination minus origin:

\[ \mathrm{relative\ position} =\mathrm{scatterer\ position}-\mathrm{reference\ position}. \]

So the fixed-orientation amplitude relative to R_ref is

\[ A_{\mathrm{ref}}(\mathbf q) =\frac{1}{V}\int_{\mathrm{body}} e^{i\mathbf q\cdot(\mathbf r-\mathbf R_{\mathrm{ref}})}\,dV. \]

Now use linearity of the dot product:

\[ \mathbf q\cdot(\mathbf r-\mathbf R_{\mathrm{ref}}) =\mathbf q\cdot\mathbf r-\mathbf q\cdot\mathbf R_{\mathrm{ref}}. \]

Then split the exponential:

\[ e^{i\mathbf q\cdot(\mathbf r-\mathbf R_{\mathrm{ref}})} =e^{i\mathbf q\cdot\mathbf r} e^{-i\mathbf q\cdot\mathbf R_{\mathrm{ref}}}. \]

The second factor does not depend on the integration variable r, so it can be pulled outside the volume integral:

\[ A_{\mathrm{ref}}(\mathbf q) =e^{-i\mathbf q\cdot\mathbf R_{\mathrm{ref}}} \frac{1}{V}\int_{\mathrm{body}} e^{i\mathbf q\cdot\mathbf r}\,dV. \]

The integral that remains is exactly the centered fixed-orientation amplitude. For the spheroid, that centered amplitude is the sphere kernel evaluated at the effective radius:

\[ A_{\mathrm{ref}}(\mathbf q) =e^{-i\mathbf q\cdot\mathbf R_{\mathrm{ref}}} K(qR_{\mathrm{eff}}). \]

This equation is the whole reason reference-point amplitudes are so manageable: moving the reference point does not change the body integral. It only multiplies the centered amplitude by a phase factor.

The sign in the phase is worth noticing. We get a minus sign because the position used in the reference amplitude is r - R_ref. If we had written the vector in the opposite direction, R_ref - r, the phase convention would be conjugated. SEB’s amplitude convention here compares the scatterer position to the reference point by using r - R_ref.

For a real randomly oriented solution, orientations with projection +qhat.R_ref and -qhat.R_ref both occur. Write the scalar projection as

\[ s_{\mathrm{ref}}=\hat{\mathbf q}\cdot\mathbf R_{\mathrm{ref}}. \]

The fixed-orientation phase factor is

\[ e^{-iqs_{\mathrm{ref}}} =\cos(qs_{\mathrm{ref}})-i\sin(qs_{\mathrm{ref}}). \]

The matching orientation with projection -s_ref gives

\[ e^{+iqs_{\mathrm{ref}}} =\cos(qs_{\mathrm{ref}})+i\sin(qs_{\mathrm{ref}}). \]

Averaging these two symmetry-related orientations cancels the imaginary parts:

\[ \frac{e^{-iqs_{\mathrm{ref}}}+e^{+iqs_{\mathrm{ref}}}}{2} =\cos(qs_{\mathrm{ref}}). \]

After orientational averaging, the imaginary sine terms cancel by symmetry. What remains is a cosine phase factor multiplying the same body amplitude K(qR_eff(u)).

The reference points are

Reference point Body-frame position
center \((0,0,0)\)
pole_a_plus \((a,0,0)\)
pole_a_minus \((-a,0,0)\)
pole_b_plus \((0,a,0)\)
pole_b_minus \((0,-a,0)\)
pole_c_plus \((0,0,c)\)
pole_c_minus \((0,0,-c)\)

The polar points project onto the scattering direction as

\[s_c=cu.\]

This gives the polar-pole cosine factor immediately:

\[\cos(qs_c)=\cos(qcu).\]

The equatorial points require one extra thought. The body is symmetric around the polar axis, but a named equatorial pole such as (a,0,0) still has an azimuthal angle relative to the transverse part of the scattering vector. We average over that azimuthal angle. For a point at equatorial radius a, the azimuthal phase average is

\[\frac{1}{2\pi}\int_0^{2\pi}\cos(qa\sqrt{1-u^2}\cos\alpha)\,d\alpha =J_0(qa\sqrt{1-u^2}).\]

Therefore

\[A_{\mathrm{pole\_a\_plus}}(q) =A_{\mathrm{pole\_a\_minus}}(q) =A_{\mathrm{pole\_b\_plus}}(q) =A_{\mathrm{pole\_b\_minus}}(q) =\int_0^1 J_0(qa\sqrt{1-u^2})K(qR_{\mathrm{eff}}(u))\,du,\]

and

\[A_{\mathrm{pole\_c\_plus}}(q) =A_{\mathrm{pole\_c\_minus}}(q) =\int_0^1 \cos(qcu)K(qR_{\mathrm{eff}}(u))\,du.\]

Specific reference-reference phase factors use only Euclidean distances:

\[\Psi_{\alpha,\omega}(q)=\frac{\sin(qd_{\alpha,\omega})}{qd_{\alpha,\omega}}.\]

Notice the bookkeeping difference. Amplitudes compare a reference point to all scatterers in the body, so they include K. Phase factors compare two reference points only, so they only need the distance between those two named points.

The code below builds these three things in the same order: named point coordinates, pole amplitudes, and distance-based phase factors.

reference_points = {
    "center": sp.Matrix([0, 0, 0]),
    "pole_a_plus": sp.Matrix([a, 0, 0]),
    "pole_a_minus": sp.Matrix([-a, 0, 0]),
    "pole_b_plus": sp.Matrix([0, a, 0]),
    "pole_b_minus": sp.Matrix([0, -a, 0]),
    "pole_c_plus": sp.Matrix([0, 0, c]),
    "pole_c_minus": sp.Matrix([0, 0, -c]),
}

A_pole_equator = sp.Integral(
    sp.besselj(0, q * a * sp.sqrt(1 - u**2)) * K,
    (u, 0, 1),
)
A_pole_polar = sp.Integral(
    sp.cos(q * c * u) * K,
    (u, 0, 1),
)

def reference_distance(ref1, ref2):
    delta = reference_points[ref1] - reference_points[ref2]
    return sp.sqrt(sum(component**2 for component in delta))

def specific_reference_phase(ref1, ref2):
    distance = reference_distance(ref1, ref2)
    if distance == 0:
        return sp.Integer(1)
    return sp.simplify(sinc(q * distance))

Psi_refs = {
    (ref1, ref2): specific_reference_phase(ref1, ref2)
    for ref1 in reference_points
    for ref2 in reference_points
}

display(Math(r"A_{\mathrm{equatorial\ pole}}(q) = " + sp.latex(A_pole_equator)))
display(Math(r"A_{\mathrm{polar\ pole}}(q) = " + sp.latex(A_pole_polar)))
display(Math(r"\Psi_{\mathrm{pole\_c\_plus,pole\_c\_minus}}(q) = " + sp.latex(Psi_refs[("pole_c_plus", "pole_c_minus")])))
display(Math(r"\Psi_{\mathrm{pole\_c\_plus,pole\_a\_plus}}(q) = " + sp.latex(Psi_refs[("pole_c_plus", "pole_a_plus")])))
display(Math(r"\Psi_{\mathrm{pole\_a\_plus,pole\_a\_minus}}(q) = " + sp.latex(Psi_refs[("pole_a_plus", "pole_a_minus")])))

\(\displaystyle A_{\mathrm{equatorial\ pole}}(q) = \int\limits_{0}^{1} \frac{\left(- 3 q \sqrt{a^{2} \left(1 - u^{2}\right) + c^{2} u^{2}} \cos{\left(q \sqrt{a^{2} \left(1 - u^{2}\right) + c^{2} u^{2}} \right)} + 3 \sin{\left(q \sqrt{a^{2} \left(1 - u^{2}\right) + c^{2} u^{2}} \right)}\right) J_{0}\left(a q \sqrt{1 - u^{2}}\right)}{q^{3} \left(a^{2} \left(1 - u^{2}\right) + c^{2} u^{2}\right)^{\frac{3}{2}}}\, du\)

\(\displaystyle A_{\mathrm{polar\ pole}}(q) = \int\limits_{0}^{1} \frac{\left(- 3 q \sqrt{a^{2} \left(1 - u^{2}\right) + c^{2} u^{2}} \cos{\left(q \sqrt{a^{2} \left(1 - u^{2}\right) + c^{2} u^{2}} \right)} + 3 \sin{\left(q \sqrt{a^{2} \left(1 - u^{2}\right) + c^{2} u^{2}} \right)}\right) \cos{\left(c q u \right)}}{q^{3} \left(a^{2} \left(1 - u^{2}\right) + c^{2} u^{2}\right)^{\frac{3}{2}}}\, du\)

\(\displaystyle \Psi_{\mathrm{pole\_c\_plus,pole\_c\_minus}}(q) = \frac{\sin{\left(2 c q \right)}}{2 c q}\)

\(\displaystyle \Psi_{\mathrm{pole\_c\_plus,pole\_a\_plus}}(q) = \frac{\sin{\left(q \sqrt{a^{2} + c^{2}} \right)}}{q \sqrt{a^{2} + c^{2}}}\)

\(\displaystyle \Psi_{\mathrm{pole\_a\_plus,pole\_a\_minus}}(q) = \frac{\sin{\left(2 a q \right)}}{2 a q}\)

4. Distributed equator reference point

The named equatorial poles are fixed points in the body frame. A different and often cleaner reference is the whole equatorial ring: choose one point uniformly around the circle where the spheroid intersects the plane z = 0.

Parameterize this distributed reference as

\[\mathbf R_e(\lambda)=\left(a\cos\lambda,\,a\sin\lambda,\,0\right), \qquad 0\le\lambda<2\pi.\]

For one fixed spheroid orientation, the projection of a point on this ring onto the scattering direction has only a transverse part. Averaging the phase around the ring gives

\[B_{\mathrm{equator}}(q,u) =\frac{1}{2\pi}\int_0^{2\pi} \cos\left(qa\sqrt{1-u^2}\cos\lambda\right)\,d\lambda =J_0\left(qa\sqrt{1-u^2}\right).\]

NoteDerivation of the equator ring factor

Use a unit scattering direction whose polar direction cosine relative to the spheroid axis is (u). Its transverse length is then

\[\sqrt{1-u^2}.\]

Choose the transverse component along the (x)-axis. A point on the equator ring is

\[ \mathbf R_e(\lambda)= \left(a\cos\lambda,\,a\sin\lambda,\,0\right). \]

The projection of this point onto the scattering direction is therefore

\[ \hat{\mathbf q}\cdot\mathbf R_e(\lambda) =a\sqrt{1-u^2}\cos\lambda. \]

For one fixed orientation (u), the ring contribution is the average phase around the ring. The sine part cancels by symmetry, so

\[ B_{\mathrm{equator}}(q,u) =\frac{1}{2\pi}\int_0^{2\pi} \cos\left(qa\sqrt{1-u^2}\cos\lambda\right)\,d\lambda. \]

Using the Bessel identity

\[ J_0(z)=\frac{1}{2\pi}\int_0^{2\pi}\cos(z\cos\lambda)\,d\lambda, \]

with (z=qa), gives

\[ B_{\mathrm{equator}}(q,u)=J_0\left(qa\sqrt{1-u^2}\right). \]

Therefore the equator-ring amplitude is

\[A_{\mathrm{equator}}(q) =\int_0^1 B_{\mathrm{equator}}(q,u) K(qR_{\mathrm{eff}}(u))\,du.\]

This is the same formula as the named equatorial-pole amplitude after orientational averaging. The distinction is semantic: pole_a_plus is one named point, while equator is a distributed point chosen uniformly from the ring.

The equator phase factors are also ring averages. Distances to the center and polar poles are constant:

\[\Psi_{\mathrm{center,equator}}(q)=\frac{\sin(qa)}{qa},\]

and

\[\Psi_{\mathrm{equator,pole\_c}}(q) =\frac{\sin\left(q\sqrt{a^2+c^2}\right)} {q\sqrt{a^2+c^2}}.\]

For an equatorial named pole, rotational symmetry lets us fix that pole at (a,0,0) and average over the ring azimuth:

NoteDerivation of the equator-to-equatorial-pole phase factor

The distributed equator point is

\[\mathbf R_e(\lambda)=\left(a\cos\lambda,\,a\sin\lambda,\,0\right),\]

and rotational symmetry lets us choose the named equatorial pole as

\[\mathbf R_a=(a,0,0).\]

The phase factor between two reference points uses the orientationally averaged Debye factor

\[\operatorname{sinc}(qd)=\frac{\sin(qd)}{qd},\]

where d is the Euclidean distance between the two points. For this pair,

\[ d^2(\lambda) =|\mathbf R_e(\lambda)-\mathbf R_a|^2 =(a\cos\lambda-a)^2+(a\sin\lambda)^2. \]

Expanding and using (2+2),

\[ d^2(\lambda) =a^2\cos^2\lambda-2a^2\cos\lambda+a^2+a^2\sin^2\lambda =2a^2(1-\cos\lambda). \]

Therefore

\[d(\lambda)=\sqrt{2a^2(1-\cos\lambda)}.\]

The equator point is chosen uniformly, so the phase factor is the azimuthal average

\[ \Psi_{\mathrm{equator,pole\_a}}(q) =\frac{1}{2\pi}\int_0^{2\pi} \frac{\sin(qd(\lambda))}{qd(\lambda)}\,d\lambda. \]

Substituting the distance gives the expression below.

This integral can also be rewritten with a Bessel identity. Since

\[ 2a^2(1-\cos\lambda) =4a^2\sin^2\frac{\lambda}{2}, \]

and ((/2)) for (0),

\[ d(\lambda)=2a\sin\frac{\lambda}{2}. \]

Use

\[ \frac{\sin x}{x}=\int_0^1\cos(tx)\,dt. \]

Then

\[ \Psi_{\mathrm{equator,pole\_a}}(q) =\int_0^1 \frac{1}{2\pi}\int_0^{2\pi} \cos\left(2aqt\sin\frac{\lambda}{2}\right)\,d\lambda\,dt. \]

With (=/2),

\[ \frac{1}{2\pi}\int_0^{2\pi} \cos\left(2aqt\sin\frac{\lambda}{2}\right)\,d\lambda =\frac{1}{\pi}\int_0^\pi \cos(2aqt\sin\theta)\,d\theta. \]

The Bessel identity

\[ J_0(z)=\frac{1}{\pi}\int_0^\pi\cos(z\sin\theta)\,d\theta \]

therefore gives

\[ \Psi_{\mathrm{equator,pole\_a}}(q) =\int_0^1 J_0(2aqt)\,dt =\frac{1}{2aq}\int_0^{2aq}J_0(s)\,ds. \]

\[\Psi_{\mathrm{equator,pole\_a}}(q) =\frac{1}{2\pi}\int_0^{2\pi} \frac{\sin\left(q\sqrt{2a^2(1-\cos\lambda)}\right)} {q\sqrt{2a^2(1-\cos\lambda)}}\,d\lambda.\]

Equivalently,

\[\Psi_{\mathrm{equator,pole\_a}}(q) =\int_0^1 J_0(2aqt)\,dt =\frac{1}{2aq}\int_0^{2aq}J_0(s)\,ds.\]

The equator-equator phase factor has the same integral, because the relative azimuth between two independently chosen ring points is uniformly distributed.

The equator,pole_a formula applies to all four named equatorial poles, and the equator,pole_c formula applies to both polar poles.

Finally, the equator-surface phase factor uses the same distance as surface to an equatorial pole, averaged over the surface measure and the relative azimuth:

NoteDerivation of the equator-to-surface phase factor

The distributed equator point is

\[ \mathbf R_e(\lambda_e) =\left(a\cos\lambda_e,\,a\sin\lambda_e,\,0\right), \]

and a point on the spheroid surface can be parameterized by

\[ \mathbf R_s(\theta,\lambda_s) =\left(a\sin\theta\cos\lambda_s,\, a\sin\theta\sin\lambda_s,\, c\cos\theta\right), \qquad 0\le\theta\le\pi. \]

The surface element comes from

\[ dS=\left| \frac{\partial\mathbf R_s}{\partial\theta} \times \frac{\partial\mathbf R_s}{\partial\lambda_s} \right|\,d\theta\,d\lambda_s. \]

For the spheroid this gives

\[ dS =a\sin\theta\sqrt{c^2\sin^2\theta+a^2\cos^2\theta}\, d\theta\,d\lambda_s. \]

The phase factor between two distributed reference points is the normalized average of the Debye factor:

\[ \Psi_{\mathrm{equator,surface}}(q) = \frac{ \int \int \frac{\sin(qd)}{qd}\,dS\,d\lambda_e } { \int\int dS\,d\lambda_e }. \]

Because the spheroid is rotationally symmetric around the polar axis, the distance depends only on the relative azimuth

\[ \lambda=\lambda_s-\lambda_e. \]

So one absolute azimuth integrates out, leaving the normalized relative-azimuth average

\[ \frac{1}{2\pi}\int_0^{2\pi}\frac{\sin(qd_{es})}{qd_{es}}\,d\lambda. \]

To get the distance, fix the equator point at ((a,0,0)) and let the surface point have relative azimuth ():

\[ \mathbf R_e=(a,0,0), \qquad \mathbf R_s(\theta,\lambda) =\left(a\sin\theta\cos\lambda,\, a\sin\theta\sin\lambda,\, c\cos\theta\right). \]

Then

\[ \begin{aligned} d_{es}^2 &=|\mathbf R_s-\mathbf R_e|^2\\ &=a^2(\sin\theta\cos\lambda-1)^2 +a^2\sin^2\theta\sin^2\lambda +c^2\cos^2\theta\\ &=a^2\left(\sin^2\theta+1-2\sin\theta\cos\lambda\right) +c^2\cos^2\theta. \end{aligned} \]

Therefore

\[ d_{es} =\sqrt{ a^2\left(\sin^2\theta+1-2\sin\theta\cos\lambda\right) +c^2\cos^2\theta }. \]

Putting the relative-azimuth average together with the normalized surface-area average gives the expression below. The factor (2) from the surface azimuth cancels between numerator and denominator, which is why only the reduced surface weight in () remains outside the inner average.

\[\Psi_{\mathrm{equator,surface}}(q) = \frac{ \int_0^\pi \frac{1}{2\pi}\int_0^{2\pi} \frac{\sin(qd_{es})}{qd_{es}}\,d\lambda\, a\sin\theta\sqrt{c^2\sin^2\theta+a^2\cos^2\theta}\,d\theta } {\int_0^\pi a\sin\theta\sqrt{c^2\sin^2\theta+a^2\cos^2\theta}\,d\theta}, \]

where

\[d_{es}= \sqrt{a^2\left(\sin^2\theta+1-2\sin\theta\cos\lambda\right) +c^2\cos^2\theta}.\]

5. Distributed surface reference point

The distributed surface reference point is different from the named poles. It is not one fixed coordinate. It means: choose one point uniformly from the spheroid surface area, then use that point as the reference point.

That creates two jobs:

  • for A_surface(q), average the reference-point phase over all possible surface points;
  • for phase factors involving surface, average the Debye factor over one or two surface points.

The important detail is that “uniformly on the surface” means uniformly with respect to surface area, not uniformly in the parameters theta and lambda. That is why we need the surface element.

Parameterize the spheroid surface as

\[\mathbf R_s(\theta,\lambda) =\left(a\sin\theta\cos\lambda,\, a\sin\theta\sin\lambda,\, c\cos\theta\right).\]

The surface-area element is

\[dS=a\sin\theta\sqrt{c^2\sin^2\theta+a^2\cos^2\theta}\,d\theta\,d\lambda.\]

We will write this as

\[dS=w(\theta)\,d\theta\,d\lambda,\]

where the reduced surface weight is

\[w(\theta)=a\sin\theta\sqrt{c^2\sin^2\theta+a^2\cos^2\theta}.\]

The corresponding reduced surface-area normalization is

\[S_{\mathrm{red}}=\int_0^\pi w(\theta)\,d\theta.\]

NoteDerivation of the surface weight

Start from the surface parameterization

\[ \mathbf R_s(\theta,\lambda) =\left(a\sin\theta\cos\lambda,\, a\sin\theta\sin\lambda,\, c\cos\theta\right). \]

A small patch in parameter space has sides given by the tangent vectors

\[ \frac{\partial\mathbf R_s}{\partial\theta} =\left(a\cos\theta\cos\lambda,\, a\cos\theta\sin\lambda,\, -c\sin\theta\right), \]

and

\[ \frac{\partial\mathbf R_s}{\partial\lambda} =\left(-a\sin\theta\sin\lambda,\, a\sin\theta\cos\lambda,\, 0\right). \]

The physical area of that patch is the magnitude of their cross product:

\[ dS= \left| \frac{\partial\mathbf R_s}{\partial\theta} \times \frac{\partial\mathbf R_s}{\partial\lambda} \right|\,d\theta\,d\lambda. \]

The cross product is

\[ \frac{\partial\mathbf R_s}{\partial\theta} \times \frac{\partial\mathbf R_s}{\partial\lambda} = \left( ac\sin^2\theta\cos\lambda,\, ac\sin^2\theta\sin\lambda,\, a^2\sin\theta\cos\theta \right). \]

Its squared magnitude is

\[ \begin{aligned} \left| \frac{\partial\mathbf R_s}{\partial\theta} \times \frac{\partial\mathbf R_s}{\partial\lambda} \right|^2 &=a^2c^2\sin^4\theta(\cos^2\lambda+\sin^2\lambda) +a^4\sin^2\theta\cos^2\theta\\ &=a^2\sin^2\theta \left(c^2\sin^2\theta+a^2\cos^2\theta\right). \end{aligned} \]

Therefore

\[ dS= a\sin\theta\sqrt{c^2\sin^2\theta+a^2\cos^2\theta}\, d\theta\,d\lambda. \]

So the reduced surface weight used throughout this section is

\[ w(\theta) =a\sin\theta\sqrt{c^2\sin^2\theta+a^2\cos^2\theta}. \]

The factor (w()) tells us how much actual area is represented by a small rectangle in parameter space.

Let

\[S=\int_0^{2\pi}\int_0^\pi dS.\]

For a fixed scattering direction with polar cosine u, the projection of a surface point is

\[p_s=a\sqrt{1-u^2}\sin\theta\cos\lambda+cu\cos\theta.\]

The azimuthal lambda average of the cosine phase gives a Bessel function:

\[\frac{1}{2\pi}\int_0^{2\pi}\cos(qp_s)\,d\lambda =J_0(qa\sqrt{1-u^2}\sin\theta)\cos(qcu\cos\theta).\]

This is the same kind of simplification we used for the equatorial poles. The transverse part becomes J0, and the polar part stays as a cosine. Thus the distributed surface phase average can be written as a one-dimensional normalized surface integral:

NoteDerivation of the surface phase factor

For a fixed orientation (u), the surface reference contribution is the surface-area average of the reference-point phase:

\[ B_{\mathrm{surface}}(q,u) =\frac{1}{S}\int_{\mathrm{surface}} \cos\left(q\,\hat{\mathbf q}\cdot\mathbf R_s\right)\,dS. \]

The normalization is the total spheroid surface area,

\[ S=\int_{\mathrm{surface}}dS. \]

Use the surface parameterization

\[ \mathbf R_s(\theta,\lambda) =\left(a\sin\theta\cos\lambda,\, a\sin\theta\sin\lambda,\, c\cos\theta\right). \]

Then

\[ \frac{\partial\mathbf R_s}{\partial\theta} =\left(a\cos\theta\cos\lambda,\, a\cos\theta\sin\lambda,\, -c\sin\theta\right), \]

and

\[ \frac{\partial\mathbf R_s}{\partial\lambda} =\left(-a\sin\theta\sin\lambda,\, a\sin\theta\cos\lambda,\, 0\right). \]

So

\[ dS= \left| \frac{\partial\mathbf R_s}{\partial\theta} \times \frac{\partial\mathbf R_s}{\partial\lambda} \right|d\theta\,d\lambda =a\sin\theta\sqrt{c^2\sin^2\theta+a^2\cos^2\theta}\,d\theta\,d\lambda. \]

Substituting this into the normalized average gives

\[ B_{\mathrm{surface}}(q,u) = \frac{ \int_0^{2\pi}\int_0^\pi \cos(qp_s)\, a\sin\theta\sqrt{c^2\sin^2\theta+a^2\cos^2\theta}\, d\theta\,d\lambda } { \int_0^{2\pi}\int_0^\pi a\sin\theta\sqrt{c^2\sin^2\theta+a^2\cos^2\theta}\, d\theta\,d\lambda }, \]

where

\[ p_s=\hat{\mathbf q}\cdot\mathbf R_s. \]

Choose the transverse part of () along the (x)-axis. Since the polar direction cosine is (u), the transverse length is (), and

\[ p_s=a\sqrt{1-u^2}\sin\theta\cos\lambda+cu\cos\theta. \]

The ()-dependent part is only in the transverse cosine term. Using

\[ \frac{1}{2\pi}\int_0^{2\pi} \cos(A\cos\lambda+B)\,d\lambda =J_0(A)\cos(B), \]

with

\[ A=qa\sqrt{1-u^2}\sin\theta, \qquad B=qcu\cos\theta, \]

we get

\[ \frac{1}{2\pi}\int_0^{2\pi}\cos(qp_s)\,d\lambda =J_0(qa\sqrt{1-u^2}\sin\theta)\cos(qcu\cos\theta). \]

The same factor (2) from the () integration appears in the numerator and denominator, so it cancels. What remains is the reduced surface-weight average over ():

\[ B_{\mathrm{surface}}(q,u) =\frac{\int_0^\pi J_0(qa\sqrt{1-u^2}\sin\theta) \cos(qcu\cos\theta) a\sin\theta\sqrt{c^2\sin^2\theta+a^2\cos^2\theta}\,d\theta} {\int_0^\pi a\sin\theta\sqrt{c^2\sin^2\theta+a^2\cos^2\theta}\,d\theta}. \]

\[B_{\mathrm{surface}}(q,u) =\frac{\int_0^\pi J_0(qa\sqrt{1-u^2}\sin\theta) \cos(qcu\cos\theta) a\sin\theta\sqrt{c^2\sin^2\theta+a^2\cos^2\theta}\,d\theta} {\int_0^\pi a\sin\theta\sqrt{c^2\sin^2\theta+a^2\cos^2\theta}\,d\theta}.\]

Once we have B_surface(q,u), the distributed surface amplitude follows the same pattern as all other amplitudes. For one fixed orientation, moving the reference point to a particular surface point contributes only a phase factor, while the volume integral over the spheroid still gives the centered body amplitude K(qR_eff(u)). Averaging the surface reference point first gives B_surface(q,u), and then averaging over spheroid orientations gives

\[A_{\mathrm{surface}}(q) =\int_0^1 B_{\mathrm{surface}}(q,u)\, K(qR_{\mathrm{eff}}(u))\,du.\]

For phase factors, there is no body amplitude. Psi_center_surface(q) averages the Debye factor from the center to one surface point. Psi_surface_pole_a(q) and Psi_surface_pole_c(q) average the Debye factor from one uniformly chosen surface point to one named pole. Psi_equator_surface(q) averages the Debye factor between one uniformly chosen equator point and one uniformly chosen surface point. Psi_surface_surface(q) averages the Debye factor between two independently chosen surface points. Axial symmetry lets us replace two absolute azimuths by one azimuthal difference, so the surface-surface integral is three-dimensional rather than four-dimensional.

Phase factors average the Debye factor between reference points:

\[ \Psi_{\alpha,\omega}(q) =\left\langle \frac{\sin(qd_{\alpha,\omega})}{qd_{\alpha,\omega}}\right\rangle. \]

\[ d_{cs}(\theta)=\sqrt{a^2\sin^2\theta+c^2\cos^2\theta}. \]

6. Small-q checks

The formulas above define the full q dependence. For validation and Guinier checks, SEB also needs the first nontrivial term near q = 0.

The workflow is:

  1. Replace every oscillatory factor by its expansion through q^2.
  2. Perform the simple orientation average.
  3. Match the result to SEB’s moment convention.

Use

\[K(z)=1-\frac{z^2}{10}+O(z^4),\]

and

\[\cos(x)=1-\frac{x^2}{2}+O(x^4),\qquad J_0(x)=1-\frac{x^2}{4}+O(x^4).\]

For an expression

\[A(q)=1-\frac{q^2M}{6}+O(q^4),\]

SEB stores the second moment M.

The cell below performs that recipe explicitly. We do not expand the full sine and Bessel formulas; we substitute only the terms needed for the q^2 moment. That keeps the algebra readable and avoids asking SymPy to do unnecessary work.

def q2_coefficient(expr):
    return sp.expand(sp.series(expr, q, 0, 4).removeO()).coeff(q, 2)

def seb_second_moment(expr):
    return sp.simplify(-6 * q2_coefficient(expr))

def truncate_q2(expr):
    return sp.expand(sp.series(expr, q, 0, 4).removeO())

    return sp.simplify(sp.Integral(expr, (u, 0, 1)).doit())

7. Numerical helper functions

The following helper functions use SymPy’s numerical evaluation of the symbolic expressions derived above.

This section has two purposes. First, it gives runnable checks for the derivation. Second, it shows what a simple numerical implementation would look like before translating formulas into C++ expressions.

The functions follow the tutorial order:

  • stable sphere kernel,
  • numerical evaluation of already-defined symbolic integrals,
  • F and the specific-reference amplitudes,
  • distance-based specific phase factors,
  • distributed-equator and distributed-surface helper functions.

The expensive spheroid_Psi_surface_surface helper is included for completeness but not called in the printed demo. Direct substitution at q = 0 would create removable 0/0 forms in the raw kernel and sinc expressions, so the helpers return the known normalized zero-angle limits explicitly.

def spheroid_kernel(z_value):
    z_number = sp.sympify(z_value)
    if z_number.free_symbols:
        return sphere_kernel(z_number)
    z_number = sp.Float(z_number, numeric_digits)
    if abs(float(z_number)) < numeric_zero_tol:
        return sp.Float(1, numeric_digits)
    return sp.N(sphere_kernel(z_number), numeric_digits)

        a: sp.Float(a_value, numeric_digits),

        return sp.Float(zero_value, numeric_digits)
    return sp.N(expr.subs(substitutions), numeric_digits)

The degenerate limit c = 0 is useful, but it has to be read carefully. The distributed surface reference collapses to two coincident disk faces, so normalized surface phase factors become thin-disk area averages. The homogeneous spheroid body, however, does not become a uniform thin disk area distribution; its projected density is inherited from the collapsed volume. Therefore the surface phase factors match the ThinDisk formulas, while the body form factor and body amplitudes do not.

        a_value**2 * (1 - uu**2) * sp.sin(ph)**2
        + b_value**2 * (1 - uu**2) * sp.cos(ph)**2
        + c_value**2 * uu**2

    )
    return spheroid_numeric(sp.Integral(ellipsoid_K**2, (u, 0, 1)), q_value, a_value, c_value)

        q * sp.simplify(ellipsoid_reff(u, 0, a, a, c))
    )
    return spheroid_numeric(sp.Integral(ellipsoid_K, (u, 0, 1)), q_value, a_value, c_value)

def ellipsoid_A_pole_a_b_equals_a(q_value, a_value, c_value):
    ellipsoid_K = sphere_kernel(
        q * sp.simplify(ellipsoid_reff(u, 0, a, a, c))
    )
    reduced_pole_average = sp.besselj(0, q * a * sp.sqrt(1 - u**2))
    return spheroid_numeric(
        sp.Integral(reduced_pole_average * ellipsoid_K, (u, 0, 1)),
        q_value,
        a_value,
        c_value,
    )

The distributed equator amplitude is identical to the equatorial pole amplitude after orientational averaging, but the phase factors use ring averages. The expression J has a removable singularity at qr = 0. A production implementation should evaluate it with the same care used in the numerical helper, either through a stable kernel helper or through a small-qr expansion.
