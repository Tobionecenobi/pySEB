# Atomic SAXS comparison with FoXS

The [later hydration-component validation](hydration-reconciliation.md)
separates water weights from exposure sampling and now reproduces FoXS's
hydration component with common exposures. The full-curve comparisons below
retain the earlier solvent and hydration conventions.

Measured 2026-10-15 using IMP/FoXS 2.25.0 from conda-forge in an isolated
environment under `/tmp`. No production scattering constants were changed.
CRYSOL was not run: no installation is available, and
[ATSAS requires registration for an academic license](https://biosaxs-com.github.io/atsas/).

## Fixed-parameter protocol

`Examples/compare_atomic_saxs_foxs.py` runs IMP in a separate interpreter and
compares it to the current pySEB build. The same first-model ATOM records are
used in both. The cases are isolated carbonyl C, O, ALA CB (CH3), C-C at 10 A,
C-O at 2 A, 1TIU model 1, and crambin 1CRN. Inputs for the simple cases are
generated by `diagnose_atomic_saxs_pepsi.py`. These incomplete molecules
are mathematical diagnostics, not physical solutes.

The grid is 101 points at q=0–0.5 inverse Angstroms. There is no experimental
fit, rescaling optimization, background, or instrument smearing. Each shape
is divided by its own I(0); RMS relative differences are unweighted.
Absolute forward intensities are also preserved in JSON.

Both FoXS calculation paths are examined through the IMP SAXS API:

- `default_fast`: the standard real-space partial-profile approximation,
  including its common `exp(-0.23*q^2)` intensity modulation.
- `reciprocal`: direct calculation using the bundled
  `formfactors-int_tab_solvation.lib` and q-dependent atomic factors.

The reciprocal table extends to 0.51 inverse Angstroms while comparisons end
at 0.5: IMP's table population uses an exclusive upper endpoint. Padding avoids
an unpopulated zero final form factor, without changing the comparison grid.

Vacuum uses FoXS `(c1,c2)=(0,0)` and solution without hydration `(1,0)`.
For the hydration sensitivity test, pySEB uses contrast 0.0167 e/A3 and
30 A3 per fully exposed group. FoXS uses
`c2 = 0.0167*30/3.50968 = 0.1427480568`, matching the default water forward
amplitude per unit exposure. This is an amplitude convention, **not** a mapping
of physical hydration-shell density. Native exposure calculations remain in
use: FoXS's default probe is 1.8 A with its form-factor radii, whereas pySEB
uses FreeSASA ProtOr radii with a 1.4 A probe. Reciprocal water coefficients
produce a tiny additional difference in forward amplitude.

## What the simple cases establish

Bare C and O vacuum intensities in reciprocal mode agree with pySEB to floating
point precision. C-C and C-O reciprocal vacuum curves also agree. With each
program's own single-atom solution amplitudes, the pair curves satisfy the
Debye interference identity to roughly 1e-13 relative error in reciprocal mode
and 1e-7 in fast mode. Pair interference is not the observed discrepancy.

The displaced-solvent Gaussian differs. The actual
[IMP 2.25.0 implementation](https://github.com/salilab/imp/blob/2.25.0/modules/saxs/src/FormFactorTable.cpp)
uses `rho*V*exp(-q^2*V^(2/3)/(16*pi))` in reciprocal mode. pySEB uses the
Fraser-style `rho*V*exp(-q^2*V^(2/3)/(4*pi))`. Although IMP's nearby comment
describes 4*pi, its executed code uses 16*pi. On the isolated carbon, an
independent analytic expression with that 16*pi exponent reproduces the
FoXS solution intensity to within 7e-14 relative error. The benchmark records
this diagnostic for bare single groups.

Near-cancellation of atomic and solvent amplitudes amplifies small differences
in their q dependence. Thus the single-carbon normalized solution curves
differ greatly even though their vacuum and forward solution intensities
match. This is not evidence of a pair-summation failure.

FoXS also uses coincident implicit hydrogens in its reciprocal group factors;
pySEB now applies finite bonded-H distances. A CH3 vacuum shape difference
of about 3.05% maximum is therefore expected from these distinct approximations.

## Protein results

RMS differences in normalized intensity, pySEB relative to FoXS:

| Structure | FoXS mode | Vacuum | No hydration | Hydration sensitivity |
|---|---|---:|---:|---:|
| 1TIU model 1 | default fast | 0.207% | 20.39% | 19.83% |
| 1TIU model 1 | reciprocal | 0.396% | 18.97% | 18.42% |
| 1CRN | default fast | 0.057% | 24.53% | 24.06% |
| 1CRN | reciprocal | 0.449% | 23.08% | 22.62% |

The large solution differences already exist with hydration disabled. A
hydration-only change cannot reconcile these curves. The closer fast-mode
vacuum agreement also should not be interpreted as greater physical accuracy:
different approximations can compensate at the protein level.

Before adopting another solvent convention, select it explicitly and source
its meaning rather than tuning the default to a particular program. The
Pepsi comparison and this FoXS comparison expose different conventions; no
single reference program establishes all components as physically correct.
CRYSOL would supply another independent check when available.

## Reproduce

Install IMP 2.25.0 in a separate environment using its
[official installation instructions](https://integrativemodeling.org/download-anaconda.html).
With pySEB built, run:

```bash
.venv-sympy/bin/python Examples/compare_atomic_saxs_foxs.py \
  --imp-python /path/to/IMP/python \
  --pdb docs/tutorials/data/1TIU-heavy-ensemble.pdb \
  --output /tmp/atomic-foxs-titin
```

Each run saves the actual input, native FoXS curves/exposures, CSV comparisons,
input checksum, version and metrics. Metric snapshots for all seven cases
are in `atomic-saxs-foxs/`. Protein inputs are the same as the
[Pepsi comparison](atomic-saxs-pepsi.md). CRYSOL remains untested.
